about the site

intended to be read on a monitor (800px minimum) through firefox.
mobile-neutral.

100% handedcoded by human. static and screenreader-accessible. written in notepad++. layout graphic sketched, finalized, and dismembered on gimp.

technical information

  1. hosted on github pages. all opinions represented across this URL are my own and do not reflect on any of the third parties used to make this site.
  2. minimal javascript. only stores graphic uniform and a global navigation (tldr; nobody wants to steal your data or anything.)
  3. imagemaps and some screenreader-unfriendly elements are present.
